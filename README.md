# 안규남 · Personal Page

경력, 학업, 활동과 관심 있는 기술·연구주제를 정리한 개인 홈페이지입니다.

- HTML / CSS / JavaScript
- 모바일 반응형 레이아웃
- 외부 서버에 의존하지 않는 로컬 웹폰트

`index.html`을 브라우저에서 열면 미리 볼 수 있습니다.
