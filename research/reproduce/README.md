# 과제 2 · 수집 및 재현 안내

수집일: 2026-10-03 (한국 날짜 기준). 웹페이지의 값은 이 날짜에 수집한 고정 데이터입니다.

## 실제 수행한 수집

1. 프라이머 클럽 https://primer.kr/club?lang=ko 에서 배치별 기업 목록을 브라우저로 렌더링했습니다. 기업 카드의 이름과 사업 설명을 추출하고 24기 13개, 25기 10개, 26기 17개의 기수 표시와 대조했습니다. 27기는 분석 범위에 넣지 않았습니다.
2. YC 공식 디렉터리 https://www.ycombinator.com/companies 의 공개 검색 서비스를 사용해 2024·2025년 배치의 회사 ID, 이름, 기수, 지역, 한 줄 소개, 상세 소개 등을 수집했습니다. 사용자 계정이나 비공개 API를 사용하지 않았습니다. 한 번의 검색에서 1,000개까지만 반환될 수 있어 연도별로 나누고 각 응답의 총 건수와 수집 건수가 일치하는지 확인했습니다. 2024년 590개, 2025년 621개였습니다.
3. 수집 당시 지역에 United States of America가 표시된 2024년 495개, 2025년 519개를 후보로 제한했습니다. 이름이나 성과로 기업을 고르지 않고 SHA-256(`startup-study-20261003:` + 기업 ID) 오름차순으로 각 연도 23개·17개를 선택했습니다.
4. 선택한 80개사의 공식 기업 소개 HTML을 별도로 내려받았습니다. 응답 상태와 SHA-256 해시는 `../data/collection-log.json`에 있습니다. 프라이머는 robots.txt의 Crawl-delay에 따라 5초 이상, YC는 1초 이상 간격으로 요청했습니다.
5. AI가 수집된 사업 소개를 요약·분류하고 원문 내용과 대조했습니다. 개인 연락처·창업자 개인정보·비공개 투자금·재무수치는 결과에 포함하지 않았습니다. 회사명이나 AI 관련 태그만으로 AI 역할을 확정하지 않았습니다. 별도의 복수 평가자 검증은 하지 않았습니다.

## 파일

- `../data/companies.json`: 공개 결과와 기업별 분류 근거. 분류는 해석이며 출처의 공식 분류가 아닙니다.
- `../data/companies.csv`: 같은 데이터의 스프레드시트용 파일.
- `../data/collection-log.json`: 개별 출처 HTML 수집 기록. 원문 전체는 재배포하지 않습니다.
- `yc-candidate-pool.json`: 수집 당시 후보 목록의 사실 항목(ID·이름·기수·지역)만 남긴 파일. 모집단 변경과 표본 선택을 구분하기 위한 기록입니다.
- `reproduce.py`: 표본 추출과 집계 재현, 선택적으로 공식 HTML 재수집.

## 재현

Python 3의 기본 라이브러리만 사용합니다. 폴더 구조를 유지한 상태에서:

```text
python reproduce.py
python reproduce.py --collect
```

첫 명령은 고정 후보 목록을 기준으로 표본을 다시 선택하고 80개 결과와 같은지 확인하며, 분류별 기업 수를 계산합니다. 두 번째 명령은 현재 robots.txt를 확인한 뒤 공개 HTML 메타데이터를 다시 수집해 `observations/`에 저장합니다. 향후 소개 변경·페이지 삭제 때문에 결과가 달라질 수 있습니다. 원래 분석의 해석 라벨을 자동으로 덮어쓰지는 않습니다.

프라이머 기수별 목록과 YC의 현재 공개 목록을 처음부터 다시 구성하는 작업은 위의 수집 절차가 별도로 필요합니다. `reproduce.py`는 수집 당시 동적 목록 전체를 재현하는 크롤러가 아니라 **고정 표본의 추출·집계 검증 및 80개 원문 재수집 도구**입니다.

## 읽을 때 주의할 점

배치 시작 연도를 맞췄지만 월·업력·매출·투자 단계는 일치시키지 않았습니다. YC의 미국 표시와 프라이머의 국내 프로그램 참여는 동일한 소재지 기준이 아닙니다. 모든 기업이 현재 프리시드·시드라고 확인된 것이 아니며, 사업 소개 역시 선정 당시의 역사 자료가 아니라 수집일 기준입니다. 성과나 국가 우열을 비교할 수 없습니다.

미확인·확인 불가도 비율의 분모에 포함합니다. B2B는 업무 목적의 전문가·개발자까지 포함합니다. AI 지원 인프라는 AI 학습·개발·운영을 돕는 데이터, 평가, 검색, 냉각 등으로 일반 업무용 AI 기능과 구분합니다. 자세한 기준은 페이지의 방법론 및 기업별 `basis` 필드를 확인하세요.
